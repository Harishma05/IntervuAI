# IntervuAI Features

## Core Features

## 1. User Authentication

- Register account
- Login securely


## 2. AI Mock Interview

- Technical interviews
- HR interviews
- DSA interviews


## 3. Answer Evaluation

AI analyzes:
- Correctness
- Explanation quality
- Missing concepts


## 4. Performance Tracking

Track:
- Scores
- Weak topics
- Interview history


## 5. Adaptive Interview

AI changes questions based on performance.


## 6. Resume Based Interview

AI generates questions from uploaded resume.


## 7. Voice Interview

User can answer using voice.


## 8. HR Resume Review

- Upload a PDF, DOCX, or TXT resume for an HR-focused readiness score.
- Review strengths, gaps, and specific improvement suggestions.
- Get likely HR interview questions grounded in the resume.
- Resume text is sent to the configured AI provider and is not stored by IntervuAI.
