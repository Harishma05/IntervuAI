# IntervuAI Features

## Core Features

## 1. User Authentication

- Register account
- Login securely


## 2. AI Mock Interview

- Technical interviews
- HR interviews
- DSA interviews


## 3. Answer Evaluation

AI analyzes:
- Correctness
- Explanation quality
- Missing concepts


## 4. Performance Tracking

Track:
- Scores
- Weak topics
- Interview history


## 5. Adaptive Interview

AI changes questions based on performance.


## 6. Resume Based Interview

AI generates questions from uploaded resume.


## 7. Voice Interview

User can answer using voice.
